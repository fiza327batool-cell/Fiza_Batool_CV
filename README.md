A modern, single-screen CV portfolio website for Fiza Batool, a
Computer Science student with experience in accounts management and
financial operations.

Overview

This project presents key CV information in a clean, professional
layout. It uses a navy-blue, royal-blue, and white visual theme, with
compact cards and interactive sections.

Features

Single-screen layout designed to avoid page scrolling.

Interactive headings for About, Education, Experience, Skills,
Projects, and Certificates & Contact.

Professional header with CV download and certificate access buttons.

Card-based design with clear typography and icons.

Resume and certificate information based on the supplied documents.

Design

Primary color: Royal blue

Background: Light blue-white

Text: Dark navy and slate gray

Style: Minimal, modern, and professional

The project keeps the original layout and structure while matching its
colors to the reference portfolio.

Project Files

Depending on the Google Stitch export, the project may include:

index.html or code.html --- main website page

style.css --- styling, if stored separately

script.js --- interactive behavior, if stored separately

documents/ --- resume and certificates, if included

Keep the exported folder structure unchanged.

Run Locally

Download or clone this repository.

Open the project folder.

Open index.html (or the exported main HTML file) in a browser.

Deployment

This static website can be deployed through Vercel by importing the
GitHub repository. Configure the project as a static site and use the
exported file structure.

Privacy

Review your resume and certificate PDFs before publishing. Documents
linked from a public website may be accessible to visitors even if the
GitHub repository is private.
